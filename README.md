# OpenBackup

OpenBackup is a local-first Windows backup application focused on one promise: a backup is not complete until it can be verified.

OpenBackup creates versioned snapshots with SHA-256 manifests, safe verified restores, persisted profiles, and schedule-aware unattended execution. The published executable accepts `--run-scheduled` for use with Windows Task Scheduler. It never deletes source files or uploads data.
